# 매칭 프로젝트 전체 세팅 및 기능 구현 기록

이 문서는 매칭 프로젝트의 초기 환경 설정(DB 포함)부터 전체적인 주요 기능들을 어떻게 기획하고 구현했는지, 그리고 어떠한 점검 과정들을 거쳤는지를 한눈에 파악하기 위해 작성된 총괄 기록 문서입니다.

## 1. 아키텍처 및 개발 환경 구성
- 프론트엔드: React + Vite (포트 5173)
- 백엔드: Spring Boot + Java (포트 8080)
- 데이터베이스: MySQL
- 통신: Axios를 통한 REST API 통신, CORS 허용 처리 완료

### 통합 실행 스크립트 구축
매번 프론트엔드와 백엔드를 따로 실행하는 번거로움을 줄이기 위해, `매칭프로젝트 시작.bat` 이라는 통합 배치 파일을 작성하여 클릭 한 번으로 DB 점검, 백엔드 구동, 프론트엔드 구동을 순차적으로 수행하도록 세팅했습니다.

## 2. 데이터베이스(DB) 세팅 기록
- 데이터베이스명: matching_db
- 접근 계정: root / 9621
- ORM 적용: Spring Data JPA(Hibernate)를 사용하여 엔티티 클래스 기반으로 테이블을 자동 생성하도록 설정(`ddl-auto: update`)
- 핵심 테이블 구조:
  - manager: 시스템을 관리하고 회원을 등록/열람하는 매니저 계정 정보
  - member: 회원의 기본 인적사항, 취미, 이상형, 자기소개 등 텍스트 정보
  - member_trait: AI가 회원의 텍스트를 분석해 도출해낸 14가지 세부 매칭 지수 (0~100점)
  - matching_history: 매니저가 두 회원을 매칭해본 기록과 AI의 종합 코멘트가 저장되는 이력 테이블
  - ai_config: 하드코딩을 피하고 운영 중에도 AI URL 및 API Key를 유연하게 바꿀 수 있도록 설계한 설정 테이블

## 3. 핵심 기능 구현 및 점검 내역

### 매니저 권한 및 로그인
- 매니저가 고유 ID를 통해 로그인하여 시스템에 접근하도록 구현했습니다.
- 비밀번호 초기화 및 권한 인증 과정을 구축하여 보안과 편의성을 점검했습니다.

### AI 기반 회원 프로파일링 (MemberTrait)
- 회원이 가입할 때 작성한 텍스트(직업, 취미, 자기소개 등)를 구글 Gemini API로 전송하여 성향을 분석합니다.
- 단순한 키워드 매칭이 아니라, 14가지 세부 지표(외향성, 가정적, 현실적 등)를 숫자로 수치화하여 DB에 저장하도록 구현했습니다.

### 매칭 알고리즘 및 UI 시뮬레이션
- 두 회원의 14가지 성향 데이터를 비교하여 궁합도를 계산하는 로직을 구현했습니다.
- 프론트엔드에서는 Recharts 라이브러리의 `Radar Chart(방사형 그래프)`를 도입하여, 두 회원의 성향이 어떻게 겹치고 어떻게 다른지 한눈에 시각적으로 파악할 수 있는 멋진 UI를 구축했습니다.

### 매칭 히스토리 (매칭 기록 보관)
- 매니저가 두 회원을 매칭해보고 괜찮다고 판단하면, 해당 매칭 이력과 함께 AI가 분석한 '두 사람의 궁합 요약 코멘트'를 DB(`matching_history`)에 저장합니다.
- 이후 '매칭 히스토리' 메뉴에서 과거에 매칭했던 내역들과 그래프를 언제든 다시 열람할 수 있도록 전체적인 뷰(View) 페이지를 점검하고 완성했습니다.

## 4. 대량의 리얼 데이터 검증 (배치 스크립트)
- 매칭 시스템을 텅 빈 데이터베이스나 랜덤 숫자 더미 데이터로 테스트하는 것은 의미가 없다고 판단했습니다.
- 이를 해결하기 위해 `회원_대량_생성기.bat` 과 `batch_generate_members.js` 스크립트를 작성하여 AI가 직접 분석한 현실적인 프로필 3,000개를 자동으로 생성하는 파이프라인을 구축했습니다.
- 데이터 현실성(Quality) 강화: 초기에 무작위 난수로 최대 1.5억 원까지 생성되던 연봉 데이터를 3,000만 원 ~ 1.2억 원 사이의 현실적인 30대 연봉 분포 배열값으로 엄격히 제한하여, AI가 대다수 회원을 '고연봉'으로 오판하는 문제를 해결하고 성향 분석의 정교함을 높였습니다.
- (자세한 API 속도 제한 해결 과정 및 유료 티어 전환 스토리는 `ai_integration_history.md` 참조)

## 5. 요약
전체적으로 백엔드의 탄탄한 DB 설계와 유연한 AI API 연동, 그리고 프론트엔드의 직관적인 방사형 그래프 UI가 잘 결합되어 완성도 높은 'AI 기반 매칭 플랫폼'의 뼈대가 성공적으로 구축 및 검증되었습니다.
