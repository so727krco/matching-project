# AI 매칭 자동화 프로파일링 비용 효율성 보고서

## 1. 개요 및 비용 분석
최근 실시한 `회원 대량 생성 배치 프로그램` 테스트 결과, **총 200명의 회원**에 대해 사진 검증 및 194개 항목의 텍스트 프로파일링을 수행하는 데 **총 2,173원**이 소요되었습니다.

* **총 대상 인원**: 200명
* **총 소요 비용**: 2,173원 (KRW)
* **1인당 평균 처리 비용**: **약 10.86원**

## 2. 1인당 10원 단위 비용 달성의 핵심 요인 (왜 효율적인가?)

현재 시스템이 이토록 압도적인 비용 효율을 달성할 수 있었던 이유는 시스템 설계와 모델 선택, 프롬프트 최적화라는 3가지 요소가 완벽하게 결합되었기 때문입니다.

### ① Gemini 3.6 Flash 모델의 가성비와 멀티모달 능력
* **최적화된 모델 선택**: 무겁고 비싼 Pro 모델 대신, 고빈도/저지연 처리에 특화된 **Gemini 3.6 Flash**를 도입했습니다. Flash 모델은 텍스트 및 이미지 처리 단가가 Pro 대비 압도적으로 저렴하면서도 '사진 내 이목구비 판별'이나 '동일인 여부'를 판독하는 데는 차고 넘치는 성능을 발휘합니다.
* **멀티모달 네이티브**: 별도의 이미지 인식(OCR 등) 모델과 텍스트 분류 모델을 나눌 필요 없이, 한 번의 호출로 사진을 눈으로 보고 바로 JSON으로 특성을 뽑아내므로 불필요한 API 왕복 비용이 전혀 발생하지 않습니다.

### ② 시스템 레벨의 '프롬프트 토큰' 최적화 (Token Optimization)
* **관심사 분리 (Separation of Concerns)**: 사진 검증 로직에서 194개의 전체 특성 리스트를 전부 프롬프트에 넣지 않고, **외모(APPEARANCE)와 관련된 약 30개의 특성만 선별**하여 AI에게 넘기도록 백엔드를 설계했습니다.
* **출력(Output) 토큰 최소화**: AI에게 불필요한 장문의 서술을 요구하지 않고, 정해진 스키마(`AiPhotoResult`, JSON) 형태의 키-값(Key-Value)으로만 대답하도록 강제하여 가장 비싼 **출력 토큰 비용을 극한으로 압축**했습니다.

### ③ 단일 호출(Single-Shot)에 검증 로직 통합
기존 시스템들이 흔히 범하는 실수인 '얼굴 인식 API 호출' -> '유해성 검사 API 호출' -> '특성 추출 API 호출'이라는 파이프라인 방식을 버렸습니다.
* 단 **한 번의 프롬프트**에 "이목구비가 명확한가?", "동일인인가?", "유해성이 없는가?", "외모 특성 점수를 추출하라"는 4가지 미션을 한 번에 지시하여 API 호출 기본료와 컨텍스트 반복에 따른 토큰 낭비를 1/4로 줄였습니다.

## 3. 인간 노동력(Human Labor)과의 압도적인 ROI 비교

매니저(사람)가 회원 1명의 프로필 글을 정독하고 사진 5장을 확인한 뒤, 194개의 특성 항목을 엑셀이나 시스템에 점수로 매기는 데는 숙련자라도 **최소 5분에서 10분**이 소요됩니다.

* **인건비 산출**: 2026년 기준 최저시급(약 10,000원 선으로 가정) 적용 시, 10분당 인건비는 **약 1,666원**입니다.
* **AI 도입 시**: 1인당 **약 10.86원**이 발생합니다.
* **비용 절감 효과**: 기존 수기 입력 대비 **약 99.3%의 비용이 절감**되며 (비용 1/150 수준), 처리 속도는 밀리초 단위로 단축됩니다. 즉, 매니저는 단순 프로파일링 업무에서 해방되어 영업과 고객 응대(CS)에만 집중할 수 있게 됩니다.

## 4. 결론
200명에 2,173원이라는 수치는 본 B2B 매칭 플랫폼 비즈니스가 **무한한 확장성(Scalability)**을 가지고 있음을 증명합니다. 하루에 2,000명의 신규 회원이 가입하더라도 서버 AI 비용은 약 21,000원에 불과하며, 이는 인건비 부담 없이 전국 단위의 매칭 비즈니스로 확장할 수 있는 완벽한 기술적 기반이 완성되었음을 의미합니다.
